# 估值模型公式契約

本文件定義平台自身的估值口徑。所有公式由後端執行，實際驗收以 golden tests 為準。

## 八個模型選項

| 選項 | API 參數 | 候選值 |
|---|---|---|
| 營收基準 | `revenue_basis` | 近 1 月、近 3 月、近 12 月 |
| 毛利率基準 | `gross_margin_basis` | 最新季、四季平均 |
| 營業費用基準 | `operating_expense_basis` | 最新季、四季平均 |
| 業外基準 | `non_operating_basis` | 預設 0、四季平均 |
| 稅後基準 | `after_tax_basis` | 最新季、四季平均 |
| 配息率基準 | `payout_basis` | 最近一年、有效年度平均 |
| 盈餘成長基準 | `growth_basis` | 近 1 年、預估、近 3 年、近 4 年 |
| EPS 模式 | `eps_mode` | 一般、減資校正 |

## 估值鏈

1. 預估季營收：近 1 月 `×3`；近 3 月為三月加總；近 12 月為十二月加總 `÷4`。
2. 預估毛利：預估季營收 `×` 所選毛利率。
3. 預估營業利益：預估毛利 `−` 所選營業費用絕對金額；四季平均先四捨五入到百萬元整數。
4. 預估稅前淨利：預估營業利益 `+` 所選業外；「預設」分支為 0，「季均」為四季平均。
5. 稅後保留率為 `本期淨利 ÷ 稅前淨利`，不可誤稱為所得稅率。
6. 預估本期淨利：預估稅前淨利 `×` 所選稅後保留率。
7. 預估母公司淨利：預估本期淨利 `−` 四季平均非控制權益淨利。
8. 預估季 EPS：預估母公司淨利 `× 最新季 EPS ÷ 最新季母公司淨利`；減資模式再
   除以 `(1 − adjust_factor)`。
9. 預估 TTM EPS：最近三個實際季 EPS `+` 預估季 EPS。

## PE 河流與目標價

- 歷史樣本是近五年「月本益比」，不是季底股價重建的 PE。
- 中心線使用算術平均值。
- 波動使用 `STDEVP`，即母體標準差。
- 七條河流為 `MAX(0, 平均 + n×σ)`，`n = -3,-2,-1,0,1,2,3`。
- 各河流目標價：河流 PE `×` 預估 TTM EPS。
- 目前 PE 推估價：目前 TTM PE `×` 預估 TTM EPS。

## 股利與報酬

- 預估現金股利：預估 TTM EPS `×` 所選配息率。
- 預估殖利率：預估現金股利 `÷` 現價。
- 「預估盈餘成長率」分支：預估季 EPS 年化（`×4`）`÷` 目前 TTM EPS `−1`。
- 預估 PEG：現價 `÷` 年化預估 EPS，再除以 `(預估盈餘成長率×100)`。
- 「預估總報酬 PE」在預估成長分支使用年化預估 EPS 的股利率，而非預估 TTM 股利率。
- 預估 TTM EPS 仍用於 PE 河流目標價與預估股利；不可和季 EPS 年化混成同一口徑。

## 名詞約束

- `tax_rate` 僅表示所得稅率；模型中的保留比例必須命名為
  `after_tax_retention_ratio`，避免把 84% 誤稱為稅率。
- `free_cash_flow` 優先定義為營業現金流減資本支出；若只有投資現金流，輸出必須標成
  `operating_plus_investing_cashflow`，不可冒充 CapEx 口徑 FCF。
- 弦值所有百分比輸入統一採 fraction（例如 ROE 8.35% 為 `0.0835`），API 額外回傳顯示尺度。
